# Анімації та шапка

Додатковий шар: `css/motion.css` та `js/motion.js`. Спільне ядро підключено на 34 сторінках; самостійна сторінка 404 залишена без змін. Стилі окремих сторінок винесено у `css/*-motion.css` й підключено лише там, де потрібні. Схема поділу — у `DELIVERY_UI.md`.

Без JavaScript зберігається попередній вигляд. Системне налаштування «Зменшення руху» вимикає нові автоматичні анімації, нахил відео й політ зерна. Навігація, ручне гортання та кнопка «Нагору» залишаються доступними; перехід нагору стає миттєвим.

## Ефекти та вимикачі

У `js/motion.js` на початку є конфігурація. Змініть відповідне `true` на `false`:

| Ключ | Що додає |
| --- | --- |
| `hero` | Послідовна поява тексту першого екрана головної. |
| `tilt` | Нахил відеоблоку до 2° за курсором, лише для миші. |
| `reveal` | Поява секцій і карток при входженні в екран, із коротким інтервалом між сусідніми елементами. |
| `header` | Звичайна шапка на початку сторінки, меню «Каталог», активні посилання, підпис кошика та видима мобільна кнопка міксу. |
| `cards` | Підйом картки, тінь через opacity, легке збільшення бейджа. |
| `fly` | Політ декоративного зерна після успішного повідомлення про додавання нового сорту. Не спрацьовує при видаленні, повторному додаванні, ліміті чи помилці збереження. |
| `drag` | Перетягування двох каруселей головної мишею; звичайний клік, клавіатура, стрілки та свайп збережені. |
| `top` | Кнопка «Нагору» з відсотком прокрутки. Під час сповіщення приховується, щоб не перекривати його. |

Для окремої сторінки можна додати до `body` атрибут, наприклад `data-mo-disable="tilt reveal fly"`. Також до завантаження `motion.js` можна задати `window.CoffeeMotionConfig = { tilt: false, reveal: false }`.

Щоб вимкнути спільні ефекти, використовуйте конфігурацію вище. Не видаляйте файли `*-motion.css`: вони також містять стилі робочих форм, модальних вікон і підвалу. Окремі анімації можна вимкнути у відповідному motion-медіаблоці.

## Обмеження інтеграції

Усі нові класи починаються з `mo-`. Кольори, радіуси та шрифти беруться з токенів `style.css`. Анімуються лише `transform` і `opacity`; CSS-анімації та переходи містяться всередині `prefers-reduced-motion: no-preference`. JS-політ додатково перевіряє цю ж умову перед запуском.

Логіку даних виконує CoffeeShop. Новий скрипт читає стан і слухає `coffee:notice`, не замінює `notify` або `addBean`, не додає товари самостійно й не змінює `.shop-notice`. Каруселі прокручуються нативно через `scrollLeft`; їхні скрипти залишені без змін.
