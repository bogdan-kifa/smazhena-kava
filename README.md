# Смажена Кава

Адаптивний сайт кавового магазину з каталогом, конструктором міксу та квізом для підбору кави.

[Відкрити сайт](https://smazhena-kava-lab12.vercel.app/)

- Каталог із пошуком, фільтрами, обраним і швидким переглядом.
- Конструктор із вибором сортів, пропорцій, обсмаження, помелу й пакування.
- Кошик, демонстраційне оформлення замовлень, профіль і збережені мікси.

Опублікована версія працює в деморежимі. Дані зберігаються в браузері. Контактна форма імітує надсилання, а оплата й реальна авторизація не підключені.

## Локальний запуск

Потрібен Node.js 24. У корені репозиторію виконайте:

```sh
node server/build.cjs
node tests/serve.cjs
```

Відкрийте [локальний сайт](http://127.0.0.1:5514/). Після змін у файлах повторіть збірку. Спільна розмітка шапки й підвалу міститься в `server/layouts/`.

## Перевірки та публікація

```sh
node tests/constructor-check.cjs
node tests/site-check.cjs
```

GitHub Actions перевіряє конструктор і статичну збірку, запускає мобільний Lighthouse та публікує сайт на Vercel після успішних перевірок. Головна гілка проєкту — `main`.

Сайт написано на HTML, CSS, Tailwind CSS і JavaScript.
