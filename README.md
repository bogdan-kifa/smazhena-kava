# Смажена Кава

**Кава, яку підбираєш під себе.**

Сайт кавового бренду з каталогом зерна, конструктором власного міксу та квізом для підбору кави за смаком.
Від знайомства із сортами до власного поєднання — в одному адаптивному інтерфейсі.

[Переглянути сайт](https://bogdan-kifa.github.io/smazhena-kava/) · [Дзеркало на Netlify](https://bogdan-kifa-lab8.netlify.app/)

## Про проєкт

«Смажена Кава» допомагає розібратися в походженні зерна, обсмаженні та смакових нотах.
Можна обрати готовий сорт або скласти персональний мікс із власними пропорціями.
Візуальний стиль поєднує теплу кавову палітру, шрифти Inter і Lora та фотографії зерна.

## Стан розробки

Реалізована браузерна логіка каталогу, кошика, конструктора міксу та квізу. Основний сайт публікується з `main`. Асортимент, характеристики та ціни демонстраційні.

Серверна авторизація та платіжна система ще не підключені. Оформлення замовлення в інтерактивній версії є демонстраційним:
контактні дані не надсилаються й не зберігаються, оплата не проводиться.

## Можливості інтерактивної версії

- **Каталог кави:** 14 позицій: 12 обсмажених і 2 зелені сорти; пошук, фільтри, сортування, обране й пагінація по 9 товарів.
- **Картка товару:** опис походження та смаку, вибір ваги й помелу; для зеленого зерна — покупка без обсмаження або вибір профілю обсмаження без доплати.
- **Конструктор міксу:** до чотирьох сортів, незалежні регулятори пропорцій, перевірка суми 100%, вибір ваги, помелу й обсмаження зеленого зерна, розрахунок вартості з пакуванням.
- **Мої мікси:** локальне збереження, редагування та повторне додавання рецептів до кошика.
- **Квіз:** три запитання, рекомендація сорту та перегляд альтернатив.
- **Кошик:** зміна кількості, видалення позицій і перерахунок підсумку.
- **Медіа:** відео, інтерактивна карта, гортання карток і кавовий факт дня.

Смаковий профіль міксу поєднує текстові ноти та графічні шкали кислотності, солодкості й гіркоти 0–10 у форматі «7,8 з 10». Це орієнтовна модель за демонстраційними оцінками сортів та обсмаженням; підсумок враховує частки складників і з’являється при сумі 100%.

Кошик, обране та рецепти зберігаються в браузері користувача. Це локальні дані, які не синхронізуються з акаунтом.
Якщо постійне сховище недоступне, інтерфейс повідомляє про тимчасове збереження.

## Технології

- Семантичний HTML5.
- CSS3, Tailwind CSS і власні дизайн-токени.
- Vanilla JavaScript без клієнтського фреймворку.
- Web Storage та Web Locks для браузерного стану інтерактивної версії.
- YouTube, Google Maps і MediaWiki API.
- Prettier для форматування та Git для контролю версій.

## Локальний запуск

```bash
git clone https://github.com/bogdan-kifa/smazhena-kava.git
cd smazhena-kava
```

Відкрий папку у VS Code та запусти `index.html` через **Live Server**.
Зібрані стилі вже є в репозиторії — для перегляду сайту встановлення залежностей не потрібне.

### Робота зі стилями

Для зміни Tailwind-стилів потрібні Node.js і pnpm.

```bash
pnpm install --frozen-lockfile
pnpm run build:css
```

Автоматичне оновлення CSS під час роботи:

```bash
pnpm run watch:css
```

Форматування вихідних файлів:

```bash
pnpm run format
```

## Пакування та обсмаження

Пакет із клапаном входить у ціну. Подарункова коробка коштує +40 ₴, багаторазова банка — +80 ₴ за одну одиницю міксу, незалежно від ваги. Доплата зберігається в рецепті та враховується в кошику й демопідсумку.

Зелену Ефіопію Guji (280 ₴/250 г) та Бразилію Cerrado (220 ₴/250 г) можна придбати без обсмаження або зі світлим, середнім чи темним обсмаженням без доплати. Помел доступний після вибору обсмаження. У конструкторі вага означає готовий мікс; обсмаження зелених складників включене у вартість.
