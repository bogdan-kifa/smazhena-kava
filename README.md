# Смажена Кава

Адаптивний сайт крафтової кав’ярні з каталогом кави,
конструктором персонального міксу та квізом для підбору зерна.

## Технології

- HTML5 та семантична розмітка
- CSS3 і Tailwind CSS
- JavaScript для каталогу, кошика, конструктора, квізу, медіа та інформера
- YouTube, Google Maps і дані Вікіпедії

## Локальний запуск

Відкрити папку проєкту у VS Code.
Запустити index.html через розширення Live Server.

## Стан проєкту

Інтерфейс магазину підготовлено.
Базова браузерна логіка каталогу, кошика, конструктора та квізу реалізована.
Серверна авторизація, справжні замовлення й оплата ще не підключені.

## Базова інтерактивність

- Каталог: пошук серед усіх 12 сортів, фільтри, сортування, обране та пагінація по 9 товарів.
- Головна: гортання добірки з шести карток кнопками та свайпом.
- Товар і кошик: вага, кількість, видалення, підсумок і спільний індикатор кошика.
- Конструктор: редагування рецептів зі збереженням їхнього ID, реальні дати збереження, індикатор смакової інтенсивності з п’яти зернин; до чотирьох сортів, незалежні повзунки 0–100%, перевірка суми 100%, вага, помел, ціна та локальне збереження рецептів. Збереження й додавання до кошика доступні лише при сумі 100%; нульові складники не включаються до збереженого рецепта.
- Квіз: три запитання, простий підбір за характеристиками та перегляд альтернатив.
- Оформлення: лише явно позначена демонстрація без відправлення чи збереження контактних даних, листів та оплати.

Кошик, обране, рецепти та останній демонстраційний підсумок зберігаються у localStorage цього браузера. Контактні дані до них не входять. Зміни між вкладками серіалізуються через Web Locks; підсумок демонстрації й очищення кошика записуються разом. Якщо постійне сховище заблоковано або Web Locks недоступні, використовується sessionStorage з попередженням про тимчасове збереження лише в цій вкладці. Якщо обидва сховища недоступні, чернетку можна змінювати на поточній сторінці, але кошик і рецепти не видаються за збережені. Це не синхронізація з акаунтом і не справжнє оформлення замовлення.

Слайдер реалізовано нативним прокручуванням. Плагіни Swiper/Fancybox та їх налаштування залишені для ЛР №10.
