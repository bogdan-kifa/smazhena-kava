# Смажена Кава

Адаптивний сайт кавового магазину з каталогом, конструктором міксу та квізом для підбору кави.

[Відкрити сайт](https://smazhena-kava-lab12.vercel.app/)

- Каталог із пошуком, фільтрами, обраним і швидким переглядом.
- Конструктор із вибором сортів, пропорцій, обсмаження, помелу й пакування.
- Кошик, демонстраційне оформлення замовлень, профіль і збережені мікси.

Опублікована версія працює в деморежимі. Дані зберігаються в браузері. Контактна форма імітує надсилання, а оплата й реальна авторизація не підключені.
